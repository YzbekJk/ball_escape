# Ball Escape

У шарика 80 секунд, чтобы вырваться из вращающихся колец. Кольца постепенно рассыпаются, а шарик отскакивает от них и ищет щель.

Открывается прямо по ссылке, ничего устанавливать не нужно. Настройки (⚙ в правом верхнем углу): время, число колец, скорость вращения, шарик, гравитация, звук, заголовок. Все значения записываются в адрес страницы, так что ссылкой можно делиться вместе с настройками.

Клавиши: `Пробел` — пауза, `R` — заново.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий и загрузите в него эти файлы.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Файлы
- `index.html`, `style.css` — страница
- `sim.js` — физика (без DOM, детерминированная; `node test.js` покажет статистику побегов)
- `app.js` — отрисовка, звук, панель настроек
