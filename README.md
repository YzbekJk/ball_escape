# Симуляции с шариком

Главное меню с двумя разделами: **Симуляции** и **Игры** (игры пока пусты, скоро появятся). Открывается прямо по ссылке, ничего устанавливать не нужно.

**Сейчас есть:**
- «Растущий шарик» — шарик отскакивает в закрытом кольце и растёт с каждым ударом.
- «Побег из колец» — шарик пробирается через вращающиеся кольца; вылетел через кольцо — оно исчезает, а остальные меняют направление вращения.
- «Сбежит ли шарик?» — шарик с гравитацией скачет внутри тонких колец и выбивает из них кусочки; когда дыры совпадут, он выпадает.
- «Добавляем сторону» — красный шарик отскакивает в многоугольнике, и с каждым ударом у фигуры становится на сторону больше, пока она не станет кругом.
- «Только 4 секунды» — шарики по очереди пытаются вылететь через щель в кольце, у каждого ограниченное время (по умолчанию 4 секунды).

В симуляции: ⚙ — настройки (значения попадают в адрес страницы, ссылкой можно делиться), ← — назад в меню. Клавиши: `Пробел` — пауза, `R` — заново, `Esc` — закрыть настройки / выйти в меню.

## Как добавить новую симуляцию
1. Скопируйте `sims/growing-ball.js` в `sims/<имя>.js` и поменяйте `id`, `title`, `desc`, `defaults`, `schema`, `preview` и код в `create`.
2. Добавьте строку `<script src="sims/<имя>.js"></script>` в `index.html` перед `app.js`.

В `Sims.register({...})` по умолчанию симуляция попадает в раздел «Симуляции». Чтобы поместить её в «Игры», добавьте `kind: 'game'`.

Меню, страница настроек, адрес с параметрами и кнопки подхватятся автоматически. Подробный образец интерфейса — в комментариях в `sims/growing-ball.js`.
