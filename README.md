# Growing Ball

Шарик отскакивает внутри закрытого кольца без выхода и с каждым отскоком становится больше. Когда он заполняет всё кольцо, игра начинается заново.

Настройки (⚙ в правом верхнем углу): рост за отскок, размер, скорость, гравитация, упругость, цвет, шлейф, звук. Все значения записываются в адрес страницы, так что ссылкой можно делиться вместе с настройками.

Клавиши: `Пробел` — пауза, `R` — заново.

Файлы: `index.html`, `style.css`, `app.js`. GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
