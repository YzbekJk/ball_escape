# Подключение аккаунтов и лидербордов (Supabase)

1. Создайте бесплатный проект на https://supabase.com (New project).
2. Откройте **SQL Editor** → **New query**, вставьте весь файл `schema.sql` → **Run**.
3. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon / public**.
4. Впишите их в `../supabase-config.js` (`url` и `key`), закоммитьте и запушьте.

Таблицы закрыты (RLS без политик), с сайта доступны только функции `lb_*`. Пароли хранятся как bcrypt-хэш.
Игры и допустимые пределы результатов — в таблице `games` внутри `schema.sql` (защита от явно невозможных чисел).
